O que é um Framework CSS?


Um framework CSS é uma biblioteca de códigos pronta com regras de design, grades de layout e componentes visuais (como botões e menus). Em vez de criar tudo do zero, você usa classes prontas no código para montar sites rápidos, bonitos e que funcionam bem em celulares e computadores.

Exemplo: Tailwind


O Tailwind CSS é um framework utilitário muito popular. Diferente do Bootstrap (que entrega componentes prontos como um botão inteiro estilizado), o Tailwind fornece pequenas classes de estilo isoladas para você montar o visual direto no elemento HTML.
